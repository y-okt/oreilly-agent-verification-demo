# 集計カード

絞り込みの行のすぐ下にある4枚のカード。今の絞り込み（地域と検索語）に合う注文の集計を出す。

## Sub-features

- `cards-total` 売上合計：キャンセルを除いた金額の合計。
- `cards-count` 注文数：キャンセルを含む件数。件数（`match-count`）と同じ数になる。
- `cards-average` 平均注文額：キャンセルを除いた注文の平均。
- `cards-cancel-rate` キャンセル率：キャンセルの件数 ÷ 注文数。

## How to get to it (user POV)

- ページを開くと見える。利用者は「上の数字」「売上合計」と呼ぶことが多い。
- 値を変える入口は、地域の絞り込みと検索の2つ。

## Driving it with control-dashboard

```bash
node $C state                      # cards に4つの値
node $C screenshot --part cards    # カードだけの画像
```

確かめ方（前提と、見えるべき状態）。前提：`doctor` が `ok: true`。`reset` の直後（最初の画面、単位は円、検索と地域は空）。

- **最初の値。** `state`。`cards` が 売上合計 ￥30,032,180・注文数 120件・平均注文額 ￥278,076・キャンセル率 10.0%。
- **地域で変わる。** `region 関東`。`cards` が 売上合計 ￥6,679,540・注文数 18件・平均注文額 ￥371,086・キャンセル率 0.0%。
- **検索で変わる。** `region すべて` → `search モニター`。`cards` が 売上合計 ￥3,484,800・注文数 13件・平均注文額 ￥316,800・キャンセル率 15.4%。
- **単位で変わる。** `open settings` → `unit 万円` → `open dashboard`。売上合計 3,003.2万円・平均注文額 27.8万円。注文数とキャンセル率は変わらない。

## Gotchas

- 値を変える入口が2つある（地域・検索）。確かめるときは、入口ごとに試す。
- 売上合計と平均注文額は、設定の表示単位に従う。
