# 売上ダッシュボードの Feature Map

このアプリにある機能の一覧。利用者から見た機能ごとに1ファイル。報告や依頼を受けたら、まずこの表で「どの機能の話か」を決め、その機能のファイルを読んでから操作する。

## 画面

| 画面 | 行き方 | 中身 |
|---|---|---|
| ダッシュボード | 開くと最初に出る。メニューの「ダッシュボード」 | 絞り込み（地域・検索・件数）、集計カード、月別売上グラフ、注文一覧 |
| 顧客の画面 | ダッシュボードの注文一覧で、顧客名を押す。顧客の画面の「前の顧客」「次の顧客」 | その顧客の注文数・合計金額と、注文の一覧 |
| 設定 | メニューの「設定」 | 金額の表示単位（円・万円） |

## 機能どうしの約束

- 件数・集計カード・月別売上グラフ・注文一覧は、いつも同じ注文の集まり（地域と検索語の両方で絞ったもの）から作られる。
- 顧客の画面の注文数・合計金額・注文の一覧は、いつも見出しの顧客の注文だけから作られる。ダッシュボードの注文一覧で、その顧客の行を足したものと同じになる。
- 金額の表示単位は、設定で選ぶとすぐに、すべての画面の金額に反映される（月別売上グラフは、設定にかかわらず、いつも万円）。

## 前提

- データは、固定の120件。ダッシュボードはビルドに含まれるデータを使い、顧客の画面は、開いたときにサーバー（`GET /api/customers/<顧客名>`）から取る。保存されるのは、表示単位の設定だけ（ブラウザに保存）。
- 操作の前に `doctor` が `ok: true` であること。最初の状態に戻すときは `reset`。
